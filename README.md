# Task 4 - Git Version Control Workflow

## Objective
Manage a DevOps project using Git best practices.

## Tools
- Git
- GitHub
- PowerShell

## Branching Strategy
- main: Stable project version
- dev: Development and integration
- feature/documentation: Feature development

## Tasks Completed
- Initialized a Git repository
- Created and managed branches
- Used meaningful commits
- Practiced pull requests and merging
- Added a .gitignore file
- Created a Git tag
- Documented the workflow using Markdown

## Workflow
1. Create a feature branch from dev.
2. Make changes and commit them.
3. Push the feature branch to GitHub.
4. Open a pull request into dev.
5. Merge the pull request.
6. Open a pull request from dev into main.
7. Tag the stable release.
